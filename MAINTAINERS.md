# Maintainers

The [ans-gateway-auth-maintainers team](https://github.com/orgs/agentnameservice/teams/ans-gateway-auth-maintainers)
maintains this repository. The
[ans-gateway-auth-reviewers team](https://github.com/orgs/agentnameservice/teams/ans-gateway-auth-reviewers)
provides reviews and issue triage.

Current membership and GitHub access are recorded in
[the organization team configuration](https://github.com/agentnameservice/.github/blob/main/peribolos.yml).
Propose membership changes there through a reviewed pull request.
